## 2025-12-29 18:45 - Bug #3: 缺少 get_instrument_info 方法

### 触发场景
首个 TradingView 信号到达：
- **币种**: PUMP-USDT-SWAP
- **周期**: 15m
- **信号**: RSI divergence 买入
- **时间**: 2025-12-29 17:45 CST

### 错误信息
```
INFO: tv_webhook received type=DIV instId=PUMP-USDT-SWAP tf=15m
ERROR: 172.18.0.1:53506 - "POST /webhook/tradingview HTTP/1.0" 500 Internal Server Error
AttributeError: 'LighterClient' object has no attribute 'get_instrument_info'
  File "/app/app/main.py", line 531, in _calculate_order_size
    inst_info = exchange.get_instrument_info(inst_id=inst_id)
```

### 根本原因
`app/main.py` 中的 `_calculate_order_size()` 函数调用 `exchange.get_instrument_info()` 获取合约信息（最小下单量、精度等），但 `LighterClient` 类没有实现该方法。

该方法在 OKX 中用于返回：
- `ctVal`: 合约面值
- `lotSz`: 最小下单量
- `lotStep`: 下单步长
- `tickSz`: 价格 tick 大小

### 修复方案
在 `lighter.py` (行 376-429) 添加 `get_instrument_info()` 方法：

```python
def get_instrument_info(self, inst_id: str) -> Optional[dict]:
    """Get instrument information compatible with OKX format."""
    # 1. 转换币种格式: "PUMP-USDT-SWAP" -> "PUMP/USDT"
    lighter_symbol = inst_id.replace("-SWAP", "").replace("-", "/")
    
    # 2. 调用 Lighter API 获取市场信息
    resp = self._run_coro(self._order_api.order_books(), timeout=10.0)
    order_books = getattr(resp, "order_books", None) or []
    
    # 3. 查找对应市场
    for market in order_books:
        if getattr(market, "symbol", "") == lighter_symbol:
            size_decimals = getattr(market, "supported_size_decimals", 0)
            price_decimals = getattr(market, "supported_price_decimals", 0)
            
            # 4. 计算最小值（基于精度）
            lot_sz = pow(10, -size_decimals)    # 例: 精度2 -> 0.01
            tick_sz = pow(10, -price_decimals)  # 例: 精度4 -> 0.0001
            
            # 5. 返回 OKX 兼容格式
            return {
                "ctVal": "1",          # Lighter 直接用基础货币
                "lotSz": str(lot_sz),
                "lotStep": str(lot_sz),
                "tickSz": str(tick_sz),
                "instId": inst_id,
                "sizeDecimals": size_decimals,
                "priceDecimals": price_decimals,
            }
```

### 关键设计决策

**为什么 ctVal=1?**
- OKX: 合约以张为单位，每张价值 ctVal USDT
- Lighter: 直接用基础货币交易，没有"张"的概念
- 设置 ctVal=1 表示 1 个单位 = 1 个基础货币

**精度如何转换为最小值?**
- `size_decimals=2` → `lotSz=0.01` (10^-2)
- `size_decimals=3` → `lotSz=0.001` (10^-3)
- `price_decimals=4` → `tickSz=0.0001` (10^-4)
