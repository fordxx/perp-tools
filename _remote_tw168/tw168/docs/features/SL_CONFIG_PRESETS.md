# 止损（SL）配置方案文档

**创建时间**: 2025-12-27
**用途**: 记录三种止损配置方案，便于随时切换和调优

---

## 📋 配置方案对比表

| 参数 | 保守型 | 平衡型 ⭐ | 激进型 |
|------|--------|----------|--------|
| `STOP_LOOKBACK_BARS` | 30 | 40 | 50 |
| `ATR_BUFFER_MULT` | 0.8 | 0.6 | 0.45 |
| `MIN_BUFFER_BPS` | 20 | 15 | 3.5 |
| **止损距离** | 较大 | 中等 | 较小 |
| **胜率** | 高 | 中等 | 低 |
| **盈亏比** | 低 | 平衡 | 高 |
| **适用场景** | 震荡市、新手 | 通用 | 趋势市、经验丰富 |

**当前使用**: 平衡型 ⭐

## 方案1: 保守型（高胜率）

### .env 配置
```bash
# Stop-loss computation
PIVOT_LEN=3
ATR_LEN=14
ATR_BUFFER_MULT=0.8            # 较大ATR缓冲
MIN_BUFFER_BPS=20              # 0.2% 最小缓冲
STOP_METHOD=lookback
STOP_LOOKBACK_BARS=30          # 较短回溯周期
```

### 特点
✅ **优势**:
- 止损距离更大，减少误触发
- 胜率更高（70%+）
- 适合震荡市场
- 适合新手/谨慎交易者

❌ **劣势**:
- 单笔风险较大（R值大）
- 盈亏比可能降低（1:1.5-2）
- 仓位较小（因为$50固定风险÷大止损距离）

### 适用场景
- 震荡市、横盘整理期
- 波动率高的市场（高ATR）
- 刚开始使用系统时
- 资金较小，不能承受频繁止损

### 预期表现
```
胜率: 65-75%
平均R倍数: 1.8R
月收益: 稳定但较低
最大回撤: 较小
```

## 方案3: 激进型（高盈亏比）

### .env 配置
```bash
# Stop-loss computation
PIVOT_LEN=3
ATR_LEN=14
ATR_BUFFER_MULT=0.45           # 较小ATR缓冲
MIN_BUFFER_BPS=3.5             # 0.035% 最小缓冲
STOP_METHOD=lookback
STOP_LOOKBACK_BARS=50          # 较长回溯周期
```

### 特点
✅ **优势**:
- 止损距离小，盈亏比高（1:3-4）
- 仓位较大（因为小止损距离）
- 单笔盈利潜力大
- 资金利用率高

❌ **劣势**:
- 胜率较低（45-55%）
- 容易被正常波动止损
- 容易被"洗盘"
- 需要较强的心理素质

### 适用场景
- 强趋势市场（单边行情）
- 经验丰富的交易者
- 追求高盈亏比策略
- 可接受较低胜率

### 预期表现
```
胜率: 45-55%
平均R倍数: 3.0-3.5R
月收益: 高波动（可能很高或很低）
最大回撤: 较大
```

⚠️ **风险警告**: 需要严格的交易纪律，容易连续止损

## 🔧 工作原理详解

### Lookback方法计算流程

```python
# 1. 获取最近N根K线
window = candles[-STOP_LOOKBACK_BARS:]

# 2. 找到极值点
if side == "buy":  # Long
    base = min(c.l for c in window)  # 最低价
else:  # Short
    base = max(c.h for c in window)  # 最高价

# 3. 计算ATR缓冲
atr_value = ATR(candles, ATR_LEN)
buffer_by_atr = atr_value × ATR_BUFFER_MULT

# 4. 计算最小缓冲
buffer_by_bps = entry_price × (MIN_BUFFER_BPS / 10000)

# 5. 取较大值作为最终缓冲
buffer = max(buffer_by_atr, buffer_by_bps)

# 6. 最终止损价
if side == "buy":
    stop_loss = base - buffer
else:
    stop_loss = base + buffer
```

### 参数影响分析

#### STOP_LOOKBACK_BARS（回溯K线数）
- **值越大** → 找到的极值点越远 → 止损距离越大 → 胜率高，盈亏比低
- **值越小** → 找到的极值点越近 → 止损距离越小 → 胜率低，盈亏比高

**举例**（1h K线，Long）:
```
LOOKBACK=30 → 回溯30小时 → 可能找到较远的低点 → SL距离大
LOOKBACK=50 → 回溯50小时 → 可能找到更远的低点 → SL距离更大
```

#### ATR_BUFFER_MULT（ATR缓冲倍数）
- **值越大** → 缓冲区越大 → 止损更宽松 → 胜率高
- **值越小** → 缓冲区越小 → 止损更紧 → 容易误触发

**举例**:
```
ATR=20, entry_price=2000

MULT=0.45 → buffer=9  → SL可能=1981 (如果base=1990)
MULT=0.8  → buffer=16 → SL可能=1974
```

#### MIN_BUFFER_BPS（最小缓冲基点）
- **值越大** → 最小保护越大 → 低波动时也有足够缓冲
- **值越小** → 低波动时缓冲不足 → 容易被噪音止损

**举例**:
```
entry_price=2000

BPS=3.5  → min_buffer=$0.70  (几乎没有保护)
BPS=15   → min_buffer=$3.00  (基本保护)
BPS=20   → min_buffer=$4.00  (较好保护)
```

## 📊 实战举例对比

### 场景：ETH-USDT-SWAP Long信号

**市场条件**:
- 当前价: $2000
- ATR(14): $25
- 1h K线

#### 保守型计算
```
LOOKBACK=30 → 30根K线最低: $1960
ATR缓冲: $25 × 0.8 = $20
MIN缓冲: $2000 × 0.2% = $4
最终缓冲: max($20, $4) = $20

止损价: $1960 - $20 = $1940
风险: $2000 - $1940 = $60 (3.0%)

仓位: $50 ÷ $60 = 0.83 ETH
TP1(1.5R): $2000 + $60×1.5 = $2090
TP4(3.5R): $2000 + $60×3.5 = $2210
```

#### 平衡型计算（当前）
```
LOOKBACK=40 → 40根K线最低: $1950
ATR缓冲: $25 × 0.6 = $15
MIN缓冲: $2000 × 0.15% = $3
最终缓冲: max($15, $3) = $15

止损价: $1950 - $15 = $1935
风险: $2000 - $1935 = $65 (3.25%)

仓位: $50 ÷ $65 = 0.77 ETH
TP1(1.5R): $2000 + $65×1.5 = $2097.5
TP4(3.5R): $2000 + $65×3.5 = $2227.5
```

#### 激进型计算
```
LOOKBACK=50 → 50根K线最低: $1945
ATR缓冲: $25 × 0.45 = $11.25
MIN缓冲: $2000 × 0.035% = $0.70
最终缓冲: max($11.25, $0.70) = $11.25

止损价: $1945 - $11.25 = $1933.75
风险: $2000 - $1933.75 = $66.25 (3.31%)

仓位: $50 ÷ $66.25 = 0.755 ETH
TP1(1.5R): $2000 + $66.25×1.5 = $2099.4
TP4(3.5R): $2000 + $66.25×3.5 = $2231.9
```

### 对比总结

| 方案 | SL价格 | 风险 | 仓位 | TP1 | TP4 |
|------|--------|------|------|-----|-----|
| 保守型 | $1940 | $60 (3.0%) | 0.83 ETH | $2090 | $2210 |
| 平衡型 | $1935 | $65 (3.25%) | 0.77 ETH | $2097.5 | $2227.5 |
| 激进型 | $1933.75 | $66.25 (3.31%) | 0.755 ETH | $2099.4 | $2231.9 |

**分析**:
- 三种方案止损距离差异不大（在这个例子中）
- 主要差异在缓冲区大小
- 保守型最不容易被误触发
- 激进型TP目标稍高，但容易被洗盘

## 🎯 切换方案指南

### 何时切换到保守型？

切换时机：
- ✅ 近期连续止损超过3次
- ✅ 市场进入震荡整理期
- ✅ 波动率突然增加
- ✅ 信心不足，需要提高胜率
- ✅ 刚开始使用系统

修改步骤：
```bash
# 编辑 .env
ATR_BUFFER_MULT=0.8
MIN_BUFFER_BPS=20
STOP_LOOKBACK_BARS=30

# 重启服务
cd ~/tw168 && docker compose restart
```

---

### 何时切换到激进型？

切换时机：
- ✅ 市场进入强趋势（单边行情）
- ✅ 近期胜率很高（>70%）但盈利不足
- ✅ 信号质量特别好
- ✅ 追求更高盈亏比
- ✅ 有足够心理承受力

⚠️ **警告**:
- 胜率会下降到45-55%
- 需要严格纪律，不能因连续止损而情绪化
- 建议配合更严格的信号筛选

---

### 何时保持平衡型？

保持时机：
- ✅ 系统运行稳定
- ✅ 胜率在55-65%之间
- ✅ 月收益符合预期
- ✅ 市场状态不明确
- ✅ **日常推荐配置** ⭐

## 📈 优化建议

### 根据时间周期调整

不同时间周期需要不同的LOOKBACK设置：

| 时间周期 | LOOKBACK建议 | 原因 |
|---------|-------------|------|
| 15m | 20-30 | 短周期，快速反应 |
| 30m | 25-35 | 短周期 |
| 1h | 30-40 | 中周期（平衡型默认） |
| 4h | 40-60 | 中长周期 |
| 1d | 50-100 | 长周期，需要更大样本 |

**当前系统主要交易周期**: 主要是15m-1h，因此平衡型的40根K线合理。

### 根据市场状态调整

| 市场状态 | 推荐方案 | ATR_BUFFER_MULT | MIN_BUFFER_BPS |
|---------|---------|----------------|---------------|
| 低波动震荡 | 保守型 | 0.8 | 20 |
| 中等波动 | 平衡型 | 0.6 | 15 |
| 高波动震荡 | 保守型 | 1.0 | 25 |
| 强趋势 | 激进型 | 0.45-0.5 | 10 |
