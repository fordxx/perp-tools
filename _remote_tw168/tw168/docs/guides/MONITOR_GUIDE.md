## 📊 快速使用


## 💡 实际使用场景

### 场景1: 每天早上检查系统
```bash
cd ~/perp-tools/_remote_tw168/tw168
./monitor.sh

# 检查：
# - 服务是否运行 ✅
# - CPU/内存正常 ✅
```


```bash

# 查看是否有开单日志
```

## 🔍 日志解读

### 健康检查日志（正常）
```
INFO: health_check uptime_s=600 last_webhook_age_s=None webhook_count=0
```
- `uptime_s`: 运行时间（秒）
- `webhook_count`: 接收到的webhook数量
- `last_webhook_age_s=None`: 还未收到任何信号

### 收到信号后
```
INFO: health_check uptime_s=650 last_webhook_age_s=15 webhook_count=1
```
- `webhook_count=1`: 收到1个信号
- `last_webhook_age_s=15`: 最后一个信号是15秒前

### 开单日志（绿色显示）
```
SUCCESS: order filled ONDO-USDT-SWAP long 50 contracts
```

### 错误日志（红色显示）
```
ERROR: failed to place order
```

## ⚠️ 注意事项

### 1. 权限问题
```bash
# 如果遇到权限问题
chmod +x monitor.sh
```

### 2. SSH密钥路径
脚本使用相对路径：
```bash
SSH_KEY="../../LightsailDefaultKey-ap-northeast-2.pem"
```
确保在正确的目录运行（`~/perp-tools/_remote_tw168/tw168/`）

### 3. 网络问题
如果SSH连接失败：
```bash
# 测试连接
ssh -i ../../LightsailDefaultKey-ap-northeast-2.pem ubuntu@3.38.98.169 "echo OK"
```

## 🛠️ 自定义监控

### 修改刷新间隔
创建自动刷新脚本 `auto_monitor.sh`:
```bash
#!/bin/bash
while true; do
    ./monitor.sh
    sleep 30  # 每30秒刷新一次
done
```

### 只看特定信息
```bash
# 只看系统状态
./monitor.sh | grep -A 5 "系统运行状态"

# 只看配置
./monitor.sh | grep -A 15 "关键配置参数"

# 只看监控币种
./monitor.sh | grep -A 20 "监控币种列表"
```

## 🎯 故障排查

### 问题1: "无法获取配置信息"
**原因**: 容器未运行或Python环境问题
**解决**:
```bash
# 检查容器状态
./monitor.sh

# 如果容器未运行
./monitor.sh restart
```

### 问题2: 监控面板卡住
**原因**: SSH连接超时
**解决**:
```bash
# Ctrl+C 退出
# 检查网络连接
ping 3.38.98.169
```

### 问题3: 看不到最新日志
**原因**: 日志可能在缓冲区
**解决**:
```bash
# 使用实时日志查看
./monitor.sh logs
```

## 📱 移动端使用

### iOS/Android Termius
1. 安装 Termius App
2. 导入SSH密钥
3. 添加 SSH 主机 `ubuntu@3.38.98.169`
4. 连接后运行：
```bash
cd ~/tw168
docker compose logs --tail=20 -f
```

### SSH快捷命令（在手机上）
```bash
# 创建别名
alias tw='cd ~/tw168 && docker compose logs --tail=20 -f'

# 使用
ssh ubuntu@3.38.98.169
tw
```
