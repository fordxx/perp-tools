# ✅ 手动信号问题修复总结

## 问题 1: 挂单成交后止盈止损未自动设置

### 根本原因
Lighter API 被限流（HTTP 429），导致后台监控任务无法查询持仓状态，因此无法检测挂单成交。

### 解决方案
降低 API 轮询频率，避免触发限流：

| 参数 | 修改前 | 修改后 |
|-----|--------|--------|
| 挂单监控间隔 | 1 秒 | **3 秒** |
| 止盈止损刷新 | 60 秒 | **120 秒** |
| 订单管理轮询 | 2 秒 | **5 秒** |

### 验证结果
✅ **0 个 429 错误**（最近 20 秒监控）
✅ 容器正常运行
✅ 配置已生效

## 问题 2: 挂单超时自动撤单

### 当前配置
```bash
ENTRY_TWO_LIMIT_TIMEOUT_CANDLES=1.0
ENTRY_TWO_LIMIT_TIMEOUT_CANDLES_BY_TF=30m:2,1h:1.5,4h:1
```

### 超时时间
| 时间周期 | 超时配置 | 实际超时时间 |
|---------|---------|-------------|
| 15m | 1.0 K线 | **15 分钟** |
| 30m | 2.0 K线 | **60 分钟** |
| 1h | 1.5 K线 | **90 分钟** |
| 4h | 1.0 K线 | **240 分钟**（4 小时） |

### 工作流程
1. 下两个限价挂单
2. 后台任务每 3 秒检查一次持仓
3. 如果超时内未成交 → **自动取消挂单**
4. 如果超时内成交 → **自动设置止盈止损**

✅ **逻辑正确，已验证**
