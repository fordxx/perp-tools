# 方案D：渐进式限价单 - 配置说明

## 核心策略

**纯限价单 + 短等待 + 严格价格阈值**

避免"信号正确仓位小，信号错误仓位大"的问题

---

## 配置参数

### 订单分配

```bash
LADDER_MARKET_PCT=0.0           # 不用市价单
LADDER_LEVEL1_BPS=3.0           # L1: 3bps（很接近市价）
LADDER_LEVEL1_PCT=0.50          # L1: 50%仓位
LADDER_LEVEL2_BPS=8.0           # L2: 8bps（中等距离）
LADDER_LEVEL2_PCT=0.30          # L2: 30%仓位
LADDER_LEVEL3_BPS=15.0          # L3: 15bps（较远）
LADDER_LEVEL3_PCT=0.20          # L3: 20%仓位
```

**设计理念**：
- L1只偏离3bps，背离成立时应该快速成交
- L2/L3逐渐远离，获取更好价格
- 不用市价单，避免滑点

---

### 等待时间配置

#### 基础等待时间（无成交时）

```bash
LADDER_WAIT_CANDLES_BY_TF="1m:1.5,3m:1.5,5m:1,15m:1,30m:0.8,1h:0.8,4h:0.5"
```

| 周期 | 等待K线数 | 实际等待时间 |
|-----|----------|------------|
| 1m  | 1.5根    | 90秒 (1.5分钟) |
| 3m  | 1.5根    | 270秒 (4.5分钟) |
| 5m  | 1根      | 300秒 (5分钟) |
| 15m | 1根      | 900秒 (15分钟) |
| 30m | 0.8根    | 1440秒 (24分钟) |
| 1h  | 0.8根    | 2880秒 (48分钟) |
| 4h  | 0.5根    | 7200秒 (2小时) |

**逻辑**：
- 如果L1都不成交，说明反转很快或信号弱
- 基础等待后放弃，避免过期信号

#### 最大等待时间（有部分成交时延长）

```bash
LADDER_MAX_WAIT_CANDLES_BY_TF="1m:3,3m:2.5,5m:2,15m:1.5,30m:1.5,1h:1.2,4h:1"
```

| 周期 | 等待K线数 | 实际等待时间 |
|-----|----------|------------|
| 1m  | 3根      | 180秒 (3分钟) |
| 3m  | 2.5根    | 450秒 (7.5分钟) |
| 5m  | 2根      | 600秒 (10分钟) |
| 15m | 1.5根    | 1350秒 (22.5分钟) |
| 30m | 1.5根    | 2700秒 (45分钟) |
| 1h  | 1.2根    | 4320秒 (72分钟) |
| 4h  | 1根      | 14400秒 (4小时) |

**逻辑**：
- 如果L1成交了，说明信号有效
- 延长等待，给L2/L3机会

---

### 价格远离阈值

```bash
LADDER_PRICE_DISTANCE_BY_TF="1m:0.2,3m:0.25,5m:0.3,15m:0.35,30m:0.4,1h:0.5,4h:0.6"
```

| 周期 | 阈值 | 说明 |
|-----|-----|------|
| 1m  | 0.2% | 价格远离L1超过0.2%立即放弃 |
| 3m  | 0.25% | 短周期严格一些 |
| 5m  | 0.3% | 中等严格 |
| 15m | 0.35% | 适度放宽 |
| 30m | 0.4% | 适度放宽 |
| 1h  | 0.5% | 长周期波动大，稍宽松 |
| 4h  | 0.6% | 超长周期，更宽松 |

**逻辑**：
- 价格快速远离 → 背离可能成立但反转太快
- 或者背离失效，价格继续突破
- 严格阈值避免"等太久信号过期还成交"

## 执行场景示例

### 场景1：5m周期，背离成立（理想情况）

```
信号价：0.284
L1: 50% @ 0.28391 (-3bps)
L2: 30% @ 0.28377 (-8bps)
L3: 20% @ 0.28358 (-15bps)

T+0s:    下单
T+30s:   价格0.28395，L1开始成交
T+60s:   价格0.28385，L1成交完毕，L2开始成交
T+120s:  价格0.28370，L2部分成交
T+300s:  基础等待到期（1根K线）
         → 有部分成交，延长等待
T+600s:  最大等待到期（2根K线）
         → 取消L2未成交部分和L3

结果：成交 L1 50% + L2 20% = 70%仓位
     平均价：0.28386
```

### 场景2：5m周期，背离失败（快速远离）

```
信号价：0.284
L1: 50% @ 0.28391 (-3bps)
L2: 30% @ 0.28377 (-8bps)
L3: 20% @ 0.28358 (-15bps)

T+0s:    下单
T+30s:   价格0.28480（上涨0.28%）
         → 距离L1: 0.31%
         → 未超过阈值0.3%，继续等
T+60s:   价格0.28520（上涨0.42%）
         → 距离L1: 0.45%
         → 超过阈值0.3%
         → 立即取消所有订单

结果：成交 0%
     避免了错误信号的仓位
```

### 场景3：5m周期，价格震荡（部分成交）

```
信号价：0.284
L1: 50% @ 0.28391 (-3bps)
L2: 30% @ 0.28377 (-8bps)
L3: 20% @ 0.28358 (-15bps)

T+0s:    下单
T+120s:  价格回调至0.28385，L1成交30%
T+180s:  价格反弹至0.28420（距离0.4%）
         → 超过阈值0.3%
         → 取消未成交订单

结果：成交 L1 30%
     部分参与，风险可控
```

## 核心优势

### ✅ 激励方向正确

```
信号正确（背离成立）：
- L1快速成交 → 至少50%仓位
- L1+L2成交 → 80%仓位

信号错误（背离失败）：
- 价格远离 → 0%仓位
- 避免满仓亏损
```

### ✅ 成本优化

```
对比纯市价单：
- L1成交价优于市价约3bps
- L2成交价优于市价约8bps
- 平均可节省3-6bps滑点
```

### ✅ 风险可控

```
最差情况：
- L1都不成交 → 0%仓位（宁可错过）

最好情况：
- 全部成交 → 100%仓位，平均价优于信号价
```

## 对比其他方案

| 方案 | 信号正确仓位 | 信号错误仓位 | 成本优化 | 复杂度 |
|-----|------------|------------|---------|--------|
| **方案D（当前）** | **50-100%** ✅ | **0-30%** ✅ | **3-6bps** | 低 |
| 方案A（30%市价+70%限价）| 30% ❌ | 70-100% ❌ | 3-15bps | 中 |
| 方案E（纯市价）| 100% ✅ | 100% ⚠️ | 0 | 最低 |

## 注意事项

1. **L1是关键**：L1只偏离3bps，如果连L1都不成交：
   - 可能是反转太快（信号超强）
   - 可能是信号太弱（价格继续原方向）
   - 无论哪种，快速放弃是对的

2. **等待时间平衡**：
   - 太短：可能错过慢反转
   - 太长：信号可能过期
   - 当前设置：1-1.5根K线（已经比之前调整长了）

3. **价格阈值关键**：
   - 严格阈值（0.2-0.6%）避免追涨杀跌
   - 如果价格已经走远，即使回调成交也是错的

---

## 后续优化方向

如果实盘效果不理想，可以调整：

1. **L1太难成交** → 增加L1 bps（3→5）
2. **等待太短** → 增加wait_candles（1→1.5）
3. **价格阈值太严** → 放宽阈值（0.3%→0.5%）
4. **仓位太保守** → 考虑添加20%市价单兜底
