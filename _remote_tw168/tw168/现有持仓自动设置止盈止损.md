# 为现有持仓自动设置止盈止损

## 问题

已经有持仓了，但止盈止损(SL/TP)没有自动挂单。

---

## 原因分析

系统有**自动刷新功能**（`_refresh_lighter_protection()`），每 60 秒检查一次持仓并自动设置止盈止损，但它需要满足以下条件：

### 必须条件

1. **有入场信息（entry_info）记录**
   - 系统需要知道：入场价格、止损价格、方向
   - 这些信息通常在下单时自动记录到 `fill_tracker` 或 `state`

2. **持仓存在且大小 > 0**

3. **没有现有的止盈止损单**（避免重复）

### 当前问题

如果持仓是**手动开的**或**通过其他方式开的**（不是通过本系统的信号），系统没有入场信息，因此自动刷新无法工作。

---

## 解决方案

### 方案 A: 通过 Lighter UI 手动设置（推荐）

直接在 Lighter 平台 UI 上为持仓设置止盈止损：

1. 登录 Lighter 平台
2. 找到对应的持仓
3. 点击"Set SL/TP"或类似按钮
4. 手动输入止损和止盈价格
5. 确认提交

**优点**:
- ✅ 最快、最直接
- ✅ 可以精确控制价格
- ✅ 不依赖系统自动逻辑

---

### 方案 B: 触发一次手动信号（让系统记录入场信息）

**注意**: 这会尝试开新单，如果不想增加仓位，需要先手动平仓一部分或全部。

#### 步骤

1. **记录当前持仓信息**
   ```
   交易对: ETH-USDT-SWAP
   方向: LONG (或 SHORT)
   入场价: 3500 (举例)
   当前仓位: 10 (举例)
   ```

2. **计算止损价格**（根据你的风险偏好）
   ```
   如果是 LONG:
   止损 = 入场价 × (1 - 止损百分比)
   例如: 3500 × (1 - 0.02) = 3430

   如果是 SHORT:
   止损 = 入场价 × (1 + 止损百分比)
   ```

3. **发送一个手动信号**（系统会记录入场信息）
   ```bash
   python3 send_manual_signal.py ETH-USDT-SWAP long -t 1h
   ```

4. **等待挂单下单和成交**
   - 系统会下两个限价挂单
   - 如果不想增加仓位，可以在挂单下单后立即手动取消
   - 或者调整仓位大小配置 `ORDER_SZ` 或 `RISK_PER_TRADE_USDT`

5. **系统会自动设置止盈止损**
   - 一旦挂单成交，后台任务会自动检测
   - 自动设置止盈止损单

**缺点**:
- ⚠️ 会尝试开新单（可能增加仓位）
- ⚠️ 需要管理额外的订单

---

### 方案 C: 使用 Lighter API/SDK 直接下止盈止损单

如果你熟悉 Lighter API，可以直接调用 API 为现有持仓下止盈止损单。

#### Lighter API 示例（伪代码）

```python
# 连接到 Lighter
from lighter import LighterClient

client = LighterClient(...)

# 获取持仓
position = client.get_position("ETH-USDT-SWAP")

# 计算止损和止盈
sl_price = position.entry_price * 0.98  # 2% 止损
tp_price = position.entry_price * 1.05  # 5% 止盈

# 下止损单
client.place_order(
    symbol="ETH/USDT",
    side="sell" if position.side == "long" else "buy",
    type="stop_loss_limit",
    trigger_price=sl_price,
    price=sl_price,
    size=position.size,
    reduce_only=True
)

# 下止盈单
client.place_order(
    symbol="ETH/USDT",
    side="sell" if position.side == "long" else "buy",
    type="limit",
    price=tp_price,
    size=position.size * 0.7,  # 70% 仓位止盈
    reduce_only=True
)
```

**优点**:
- ✅ 完全控制
- ✅ 不增加仓位

**缺点**:
- ⚠️ 需要了解 Lighter API
- ⚠️ 需要编写自定义代码

## 自动刷新为什么不工作

### 检查自动刷新状态

```bash
# 1. 检查配置
ssh ubuntu@3.38.98.169 "grep LIGHTER_REFRESH ~/tw168/.env"

# 应该看到:
# LIGHTER_REFRESH_ENABLED=true (或默认启用)
# LIGHTER_REFRESH_SECONDS=60

# 2. 检查日志
ssh ubuntu@3.38.98.169 "docker logs tw168-tv-okx-1 --tail 200 | grep -i refresh"

# 应该看到定期的刷新日志
```

### 自动刷新需要什么

查看代码 `app/main.py` 第 1445-1520 行，自动刷新需要：

1. **entry_info 存在**（从 `fill_tracker` 获取）
   - 或者从 `state.get_entry()` 获取（需要在 6 小时内有信号）

2. **持仓大小 > 0**

3. **没有现有的止盈止损单**

### 如果自动刷新不工作

**可能原因**:
1. 没有 `entry_info`（持仓不是通过本系统开的）
2. `entry_info` 已过期（超过 `LIGHTER_ENTRY_TTL_SECONDS = 21600` = 6 小时）
3. 已经有止盈止损单存在
